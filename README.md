# CADE: Clean Anomaly Detection Evaluation

Reproducible experimental pipeline for the paper "How Evaluation Protocols Inflate Time-Series Anomaly Detection Performance: A Multi-Model Reproducibility Study" (submitted to Mathematics, MDPI).

Authors: Silvester Dian Handy Permana, T. K. Abdul Rahman, Rahmat Adi Syahputra, Wahyu Caesarendra.

## Status

This repository will be populated with complete code, notebooks, and result artifacts upon paper acceptance. Currently contains project description only.

## Planned Contents

- Colab notebooks for all experiments (data setup, model training, evaluation, statistical tests, figures)
- Raw per-experiment results (CSV files, 2970 runs total)
- Summary statistics (JSON files)
- Generated figures (PNG and PDF, 300 dpi)
- README with step-by-step reproduction guide

## Datasets Used

- UCR Anomaly Archive: https://www.cs.ucr.edu/~eamonn/time_series_data_2018/
- Server Machine Dataset (via OmniAnomaly): https://github.com/NetManAIOps/OmniAnomaly
- Numenta Anomaly Benchmark: https://github.com/numenta/NAB
